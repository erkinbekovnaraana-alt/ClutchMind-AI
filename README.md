# ClutchMind AI

ClutchMind AI is a project that explores how stress affects human performance using data analysis.

## Idea
This project is based on the concept of "clutch performance" — when individuals perform exceptionally well under pressure.

## What it does
- Analyzes relationship between stress and performance
- Visualizes patterns
- Demonstrates optimal stress levels

## Tech
- Python
- pandas
- matplotlib

## Output
The model shows that performance increases with stress up to a point, then decreases.
